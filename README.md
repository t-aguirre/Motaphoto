<h1 style="color: red;">📷 MOTAPHOTO</h1>

**Nathalie Mota** is an event photographer who requires a responsive and green **WordPress** site named Motaphoto.

## 🔹 Objective

Her two main goals are:
- To increase her visibility and get recognized.
- To share photo series with her clients.


## 🔹 Main Features

    - Burger menu in tablets and mobiles 
    - Hero section with background images that loop every time the page is refreshed
    - Image gallery with a three option filter
    - Button to load more images without refreshing the page 
    - Contact modal that can be accessed from the navigation and the contact button
    - Lightbox triggered by clicking the fullscreen icon on each gallery item
    - Prev/Next navigation links that show the image of each CPT item on hover
    

## 🔹 Projet
This is a parent WordPress theme developed with the starter theme **Underscores**.  

## 🔹 Installation
To work with this project, you need to have the following tools installed:

- [Node.js](https://nodejs.org/)
- [Sass](https://sass-lang.com/)

To get started, first install the dependencies. Then, to start watching and compiling your Sass files, run:

```bash
npm install
npm run sass
```
